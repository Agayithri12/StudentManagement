Student Management System

A simple Student Management System built using HTML, CSS, and JavaScript.
This project allows users to add, view, and delete student records dynamically in a table.

# Features

1. Add student details (Name, USN, Age, Course)
2. Prevents duplicate student entries
3. Displays student list in a table
4. Delete student records
5. Clean and responsive UI
6. No database required (pure frontend)

# Technologies Used

1. HTML5
2. CSS3
3. JavaScript (DOM Manipulation)
